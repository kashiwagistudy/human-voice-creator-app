# 人力ボイス

自分の声をひらがな一音ずつ録音しておき、入力した文章をその声で読み上げる、音声バンク型のWebアプリです。合成音声ではなく「自分自身の声」で会話できることを目指しています。

## 使い方

1. `index.html` をブラウザで開く（または GitHub Pages で公開した URL にアクセスする）
2. 「音声の登録」を開き、ひらがなを1つずつ選んで🎤で自分の声を録音する
3. 上部の入力欄に文章を入力し、「この内容で話す」を押すと、録音した声で読み上げる
4. よく使う言葉はワンタップで再生できる

## データについて

録音した音声はブラウザ内の IndexedDB にのみ保存され、外部のサーバーには一切送信されません。「設定」から JSON 形式でバックアップ・復元ができます。

## 動作環境

マイク録音には `getUserMedia` に対応したブラウザ（Chrome、Safari、Edge など）が必要です。
