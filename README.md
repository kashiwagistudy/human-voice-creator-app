# 人力ボイス

自分の声を残しておき、入力した文章をその声で読み上げる、音声バンク型のWebアプリです。合成音声ではなく「自分自身の声」で会話できることを目指しています。声が出ない方・出しにくい方が、今ある手段で自分の声を使い続けられるように作っています。

## できること

- **ひらがな一音ずつ録音**：マイクで一音ずつ声を残す、基本の使い方
- **フレーズをまるごと登録**：「ありがとう」「痛いです」などの言葉を、一音ずつのつなぎ合わせより自然な、まとまった声で登録（優先して再生されます）
- **音声・動画ファイルからの取り込み**：今は声が出せない・録音しにくい方向けに、過去に撮った動画や音声メッセージから音声を取り込み、開始・終了秒を指定して登録できます
- **はい／いいえボタン**：即答が必要な場面のためのワンタップ再生
- **合成音声フォールバック**：録音が済んでいない音やひらがな以外の文字でも、端末の合成音声（Web Speech API）で無言にせず読み上げます（設定でON/OFF可）
- **バックアップ／復元**：録音データをJSON形式でエクスポート・インポート

## 使い方

1. `index.html` をブラウザで開く（または GitHub Pages で公開した URL にアクセスする）
2. 「音声の登録」を開き、「ひらがな一音ずつ」または「フレーズをまるごと」を選んで、🎤で録音するか📁でファイルから取り込む
3. 上部の入力欄に文章を入力し、「この内容で話す」を押すと、録音した声（優先）または合成音声で読み上げる
4. よく使う言葉やはい／いいえはワンタップで再生できる

## データについて

録音した音声はブラウザ内の IndexedDB にのみ保存され、外部のサーバーには一切送信されません。「設定」から JSON 形式でバックアップ・復元ができます。

## 動作環境

マイク録音には `getUserMedia` に対応したブラウザ（Chrome、Safari、Edge など）が必要です。動画ファイルからの音声取り込みは、動画の形式によってはブラウザが直接デコードできない場合があり、その際は動画を再生しながら音声のみを抽出します（動画の長さ分、多少時間がかかります）。
